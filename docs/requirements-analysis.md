# 影知需求分析

## 背景与目标

很多用户希望把公开视频保存到本地，用于学习、整理资料、离线观看或批量归档。部分平台不提供下载入口，或者下载功能存在清晰度、数量、设备端限制。本项目目标是提供一个轻量、易用、移动端友好的视频下载网站，让用户输入一个或多个公开视频链接后，完成解析、格式选择和下载。

首版强调学习和技术验证，基于开源项目 yt-dlp 封装能力，不自行实现平台解析规则，尽量降低开发复杂度和维护风险。

## 目标用户与核心场景

- 学生或学习者：保存公开课程、公开视频素材，便于离线观看。
- 内容运营者：批量保存公开资料，整理归档。
- 开发学习者：通过完整项目学习 AI 辅助开发、全栈联调和开源项目封装。

核心流程：

1. 用户粘贴一个或多个公开视频 URL。
2. 系统解析视频标题、封面、时长、平台和可用格式。
3. 用户选择格式，优先尝试直链下载。
4. 直链不可用时，改用服务端代理下载。
5. 下载完成后，用户从浏览器保存文件。

## MVP 范围

本轮实现阶段 1 到阶段 3：

- FastAPI 后端与 yt-dlp 服务封装。
- Vue3 + Vite + Tailwind CSS 前端。
- 完整 URL 解析、视频信息展示、格式选择、下载任务、文件下载闭环。
- 文档沉淀，便于后续 AI 继续扩展。

本轮不实现：

- 用户登录、数据库、云端历史记录。
- 真实支付、会员系统、额度系统。
- AI 总结、字幕翻译的真实调用。
- 绕过 DRM、验证码、登录态、平台风控或账号限制。

## 风险边界

产品必须明确提醒用户尊重版权和平台规则。首版只支持 yt-dlp 可解析的公开视频链接，不支持上传 cookies，不提供破解、绕过风控或下载受保护内容的能力。

用户自行承担平台规则、版权合规和账号风险。本项目定位为学习和技术研究用途。

## 抖音下载策略

抖音必须作为首批重点平台支持，但只支持公开视频分享链接。用户可以直接粘贴完整分享文本，前端会自动提取其中的 `https://v.douyin.com/...` 或 `https://www.douyin.com/...` 链接。

项目不要求、也不接收用户 Cookie。若某条视频需要登录态、验证码、风控校验或平台鉴权，服务端会返回明确失败提示，而不是让用户上传 Cookie。扫码登录自动获取 Cookie 只适合用户自己电脑上的本地工具，不适合公共网站；浏览器插件读取用户当前浏览器登录态也只能作为未来本地增强形态，不纳入当前网站 MVP。

## 下载模式策略

- 直链可用且未过期：返回 302 重定向到直链，减少服务器带宽和存储占用。
- 直链不可用或存在防盗链：创建服务端下载任务，下载后由服务器提供文件。
- 大文件大于 500MB：服务端使用分块流式响应，避免一次性读入内存。

## 后续扩展方向

- 字幕下载、字幕翻译、视频总结。
- 下载历史记录、用户空间、云端文件保存。
- 付费会员、批量额度、并发队列。
- 更多下载策略，例如限速、断点续传、异步任务队列和文件自动清理。
